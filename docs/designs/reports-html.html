ZED reports as HTML pages, with a new design

Every report (assessment, handholding milestone and surveillance) becomes a page built from the unit's data each time it is opened, the way the Pledge certificate works today. No PDF file is stored. The applicant opens the report and presses Download PDF to save it on their own computer or phone. Below: how it works, then the new design, page by page.

1. How the applicant gets the report

Today

  • The server draws a PDF and saves it in a folder (PDFs/SA/…/Silver_Report.pdf, and similar for handholding and surveillance).
  • "Download Report" sends that PDF file.
  • The design is fixed in code: plain grey tables, with no summary of results.

Proposed NEW

  • "View Report" opens the report page in the portal (web) or in the browser (ZED MSME app, assessor app and consultant app).
  • A bar at the top has Download PDF and Print. Download PDF saves an A4 PDF of exactly this page to the applicant's device. Nothing is kept on the server.
  • The page always shows the latest data, so a corrected remark appears at once.
  • The certificate e-mail carries a View report link (sign-in needed) instead of a PDF attachment.
  • Handholding milestone reports already saved as PDFs, and reports of rejected applications, stay downloadable as they are. New ones use the page.
  • Each report ends with a QR code that opens the public verification page, the same as on the certificate.

Bronze uses the same pages with "Desktop assessment"; ZED-X and the Admin's own levels use their badge and artwork. Pages are A4 and break cleanly when printed.

Staff, assessors, consultantsAssessment results, remote assessment, assessor app and consultant app report listsOpen the same page; staff can view a draft before final submit, marked "DRAFT".
