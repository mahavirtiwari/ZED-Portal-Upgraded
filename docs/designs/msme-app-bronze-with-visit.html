ZED MSME app: Bronze with a visit

When the Admin gives Bronze a flow with a visit (Desktop + Onsite, Desktop + Remote, Onsite only or Remote only), the app shows the visit's own steps for that Bronze, exactly as it does for Silver and Gold. A Bronze assessed at the desktop only looks as it does today. The example below is a Bronze with Desktop + Onsite whose desktop step is done and whose onsite visit is scheduled.

3. What decides which steps a Bronze shows

Bronze recordSteps shownCertified when
Flow Desktop only (today's Bronze), or no flow setBasic info → Desktop → Certifieddesktop final submit
Flow Desktop + Onsite / Desktop + RemoteBasic info → Desktop → Onsite / Remote Assessment → Certifiedafter the visit
Flow Onsite only / Remote onlyBasic info → Onsite / Remote Assessment → Certifiedafter the visit
Already certified at the desktop, flow changed laterBasic info → Desktop → Certified (unchanged)(already certified)

Notes for review

  • The steps follow the Bronze record (how it is being, or was, assessed), not only the level's current flow. That way a unit certified at the desktop never starts to show a visit step because the Admin changed the flow afterwards.
  • Only the Bronze card, the Bronze screen and its VIEW DETAILS change. Silver, Gold, ZED-X, the levels the Admin added and the surveillance screens stay as they are.
  • No new screens and no new flow. A Bronze onsite visit is the existing onsite assessment in the site assessor app (allotment, check-in, photos and videos, the lead assessor's review), and a Bronze remote visit is the remote assessment Silver and Gold use today. The "Remote Assessment" option and the NC screens are the ones Silver and Gold use; only the certificate artwork and QR code at the end are Bronze's own.
  • To build it, the server sends the Bronze stage on Silver's scale for a Bronze with a visit (desktop, visit, certified), with its remote assessment status and the visit's date. The app takes Bronze's steps from that, falling back to the flow while the server has not said.
